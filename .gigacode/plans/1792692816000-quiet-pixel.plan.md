## Задача 1: Перевод API на HTTPS

**Файлы:**
- `app/src/main/java/com/example/iss/data/RetrofitClient.kt`
- `app/src/main/res/xml/network_security_config.xml`

**Изменения:**
1. Изменить `BASE_URL` в `RetrofitClient` с `http://api.open-notify.org/` на `https://api.open-notify.org/`
2. Обновить `network_security_config.xml` — убрать `cleartextTrafficPermitted="true"` для `api.open-notify.org`
3. Убедиться, что `en.wikipedia.org` и `upload.wikimedia.org` остаются с `cleartextTrafficPermitted="false"`

## Задача 2: Убрать WRITE_EXTERNAL_STORAGE

**Файлы:**
- `app/src/main/AndroidManifest.xml`

**Изменения:**
1. Удалить разрешение `WRITE_EXTERNAL_STORAGE` — OSMDroid 6.1.20 с minSdk 24 использует собственный кэш через `Context.MODE_PRIVATE`, внешнее хранилище не требуется
2. Если OSMDroid требует кэш на SD-карте (проверить при билде) — заменить на `context.getExternalFilesDir()` без разрешения

## Задача 4: Улучшить error handling и retry логику

**Файлы:**
- `app/src/main/java/com/example/iss/viewmodel/IssViewModel.kt`
- `app/src/main/java/com/example/iss/viewmodel/AstroViewModel.kt`

**Изменения в IssViewModel:**
1. Добавить **retry логику** с экспоненциальной задержкой (1s → 2s → 4s → 8s → max 30s)
2. Добавить **отображение ошибки** в UI (error state с сообщением)
3. Добавить **timeout** для Retrofit запросов (30s read, 15s connect)
4. Добавить **circuit breaker** — если 10 попыток подряд провалились, остановить polling и показать ошибку
5. Сделать delay адаптивным — увеличивать при ошибках, сбрасывать при успехе

**Изменения в AstroViewModel:**
1. Добавить retry логику (3 попытки с задержкой 1s)
2. Добавить timeout для Retrofit
3. Улучшить обработку ошибок — конкретные сообщения для network error, timeout, parsing error
